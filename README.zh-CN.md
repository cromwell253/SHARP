# SHARP材料说明

本目录包含七份最终实验输入、SHARP模型代码、三种子五组配置的105份可重载权重，以及对比、消融和工程实验结果。

数据目录每个工作面只有`series.npz`（唯一数组`data`）和`coordinates.csv`。应力读数保持实验所用float32值与节点顺序；真实日期、原测点标签和内部目录标记已清理，坐标平移到首个测点为原点。图输入、划分和几何分块另存于configs，以支持模型重建。

安装与运行见英文README。`evaluate.py`可评价SHARP、PatchSTG、C0、H、S；`replay.py`可逐分钟回放。正式结果保持原值，新评价默认写入runs，不覆盖论文结果。

英文README和docs/EXPERIMENTS.md区分已支持的权重重载评价、两项纠正模块的阶段训练，以及未在此目录重新验证的第三方基线训练范围。不能把公开历史结果表等同于本次重新训练全部基线。
